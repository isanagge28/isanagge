# Isana — Второй мозг для Claude

Плагин для Claude Code. Ставишь один раз — и Claude:
- создаёт тебе папку **«Второй мозг»** с памятью: правила, оглавление, ссылки, уроки, журнал «где остановились» — **на выбор только на компьютере или с копией в облаке** (Google Диск, iCloud, Dropbox, OneDrive);
- **работает с нескольких компьютеров**: ноутбук и рабочий компьютер видят один Второй мозг, сохранённые приёмы подключаются сами, при старте Claude напоминает, на чём вы остановились;
- **всё, что создаёт, сохраняет туда же**: документы — в `Документы/`, программы и проекты — в `Проекты/`, входящее — во `Входящие/`;
- знакомится с тобой и дальше работает под твоё дело;
- **сам становится лучше**: удачные приёмы сохраняет навыками, ошибки — уроками;
- **сам раскладывает файлы по папкам**: напоминает перед работой и наводит порядок по просьбе «отсортируй»;
- **смотрит ссылки и видео**: статьи, YouTube, Reels, TikTok — читает, слушает, смотрит кадры;
- **расшифровывает голосовые** бесплатно и без интернета (Whisper) и сразу делает, что ты попросил;
- умеет делать **видео** (HyperFrames, GSAP), **живые тексты** (humanizer), **анализ таблиц** (data-analysis), **карту знаний** (graphify), **проверку кода на дыры** (security-audit) и **искать новые навыки** (find-skills).

## Установка

В Claude Code вставь по очереди:

```
/plugin marketplace add isanagge28/isanagge
/plugin install isanagge@isanagge
```

Перезапусти Claude Code и напиши «привет» — Claude предложит создать Второй мозг.

**Обновление.** Новая версия: `/plugin marketplace update isanagge`, потом перезапуск. Чтобы обновлялось само — в `/plugin` открой «Marketplaces» → `isanagge` и включи автообновление (если в твоей версии Claude Code есть такой переключатель).

## Несколько компьютеров и облако

Три слоя — у каждого своё место:

| Что | Где живёт | Как попадает на другой компьютер |
|---|---|---|
| Плагин (навыки Isana и их улучшения) | GitHub | Обновлением плагина |
| **Облачный Второй мозг**: правила, проекты, документы, уроки, журнал, **твои приёмы** | Облако, папка «Облачный Второй мозг» (советую Google Диск в режиме «Зеркалирование» — файлы и на диске, и в облаке) | Само, программой облака |
| Программы (Whisper, yt-dlp, ffmpeg) и метка `~/.isanagge/config.json` | Сам компьютер | Ставятся один раз на каждом |

- Начал без облака — в любой момент скажи «перенеси Второй мозг в облако».
- Второй компьютер: поставь облако и плагин, напиши «привет» и выбери «Второй мозг у меня уже есть».
- Работай по очереди: перед тем как закрыть компьютер, дождись значка «синхронизировано».
- Большие проекты (код, тяжёлые видео) — в GitHub или отдельной папке; во Втором мозге — только карточка со ссылкой. Так он остаётся лёгким.
- Твой Второй мозг в GitHub не попадает: в репозитории только плагин.

## Что внутри

| Навык | Что делает |
|---|---|
| `start` | Первый запуск: где держать Второй мозг (компьютер / облако / уже есть), знакомство, перенос старых документов, установка нужного |
| `sinhronizaciya` | Перенести Второй мозг в облако, подключить второй компьютер, синхронизировать приёмы |
| `novyy-proekt` | Новый проект — своя папка (или карточка со ссылкой для большого) и строка в оглавлении |
| `zapomni-priem` | Сохранить удачный приём как навык — во Втором мозге, доступен на всех компьютерах |
| `sortirovka` | Навести порядок: разложить файлы и проекты по папкам, обновить оглавление |
| `watch` | Прочитать ссылку или посмотреть видео (субтитры/Whisper + кадры) и сделать, что просили |
| `itog-nedeli` | Итог недели: что получилось, что улучшить |
| `rasshifrovka` | Голосовые и видео → текст (Whisper), Claude сразу действует |
| видео | `hyperframes`, `hyperframes-cli`, `hyperframes-registry`, `figma`, `media-use`, `remotion-to-hyperframes`, `reverse-any-video`, `slideshow`, `style-sampling`, `gsap-*` |
| тексты и поиск | `humanizer`, `find-skills` |
| анализ | `data-analysis`, `security-audit` (+ `graphify` ставится при первом запуске) |

## Безопасность

- Плагин ничего не создаёт и не ставит без твоего «да».
- **В GitHub ничего не загружается само.** Твой Второй мозг и проекты остаются у тебя и в твоём облаке. Если попросишь загрузить проект — он уйдёт отдельным репозиторием, и Claude каждый раз спросит: **закрытый** (для себя) или **открытый** (для всех — готовые плагины). Перед открытым он проверит, чтобы не было личного.
- При старте плагин только читает файл-метку `~/.isanagge/config.json` и подсказывает Claude, где твой Второй мозг. Без интернета.
- Программы (graphify, Whisper) ставятся только из официальных источников и только с согласия.
- Чужие навыки скопированы без изменений из официальных открытых репозиториев — см. [THIRD_PARTY.md](THIRD_PARTY.md).
