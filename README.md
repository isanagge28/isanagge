# Isana — Второй мозг для Claude

Плагин для Claude Code. Ставишь один раз — и Claude:
- создаёт тебе папку **«Второй мозг»** (спросит, где) с памятью: правила, оглавление, ссылки, уроки;
- **всё, что создаёт, сохраняет туда же**: документы — в `Документы/`, программы и проекты — в `Проекты/`, входящее — во `Входящие/`;
- знакомится с тобой и дальше работает под твоё дело;
- **сам становится лучше**: удачные приёмы сохраняет навыками, ошибки — уроками;
- **сам раскладывает файлы по папкам**: напоминает перед работой и наводит порядок по просьбе «отсортируй»;
- **смотрит ссылки и видео**: статьи, YouTube, Reels, TikTok — читает, слушает, смотрит кадры;
- **расшифровывает голосовые** бесплатно и без интернета (Whisper) и сразу делает, что ты попросил;
- умеет делать **видео** (HyperFrames, GSAP), **живые тексты** (humanizer), **анализ таблиц** (data-analysis), **карту знаний** (graphify), **проверку кода на дыры** (security-audit) и **искать новые навыки** (find-skills).

## Установка

В Claude Code вставь по очереди:

```
/plugin marketplace add isanagge28/isanagge
/plugin install isanagge@isanagge
```

Перезапусти Claude Code и напиши «привет» — Claude предложит создать Второй мозг.

## Что внутри

| Навык | Что делает |
|---|---|
| `start` | Первый запуск: папка «Второй мозг», знакомство, перенос старых документов, установка нужного |
| `novyy-proekt` | Новый проект — своя папка и строка в оглавлении |
| `zapomni-priem` | Сохранить удачный приём как навык |
| `sortirovka` | Навести порядок: разложить файлы и проекты по папкам, обновить оглавление |
| `watch` | Прочитать ссылку или посмотреть видео (субтитры/Whisper + кадры) и сделать, что просили |
| `itog-nedeli` | Итог недели: что получилось, что улучшить |
| `rasshifrovka` | Голосовые и видео → текст (Whisper), Claude сразу действует |
| видео | `hyperframes`, `hyperframes-cli`, `hyperframes-registry`, `figma`, `media-use`, `remotion-to-hyperframes`, `reverse-any-video`, `slideshow`, `style-sampling`, `gsap-*` |
| тексты и поиск | `humanizer`, `find-skills` |
| анализ | `data-analysis`, `security-audit` (+ `graphify` ставится при первом запуске) |

## Безопасность

- Плагин ничего не создаёт и не ставит без твоего «да».
- При старте плагин только читает файл-метку `~/.isanagge/config.json` и подсказывает Claude, где твой Второй мозг. Без интернета.
- Программы (graphify, Whisper) ставятся только из официальных источников и только с согласия.
- Чужие навыки скопированы без изменений из официальных открытых репозиториев — см. [THIRD_PARTY.md](THIRD_PARTY.md).
