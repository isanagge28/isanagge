# Isana: первый запуск

Говори по-русски, на «ты», коротко и по-доброму. Человек может быть полным новичком: без терминов, а если без термина никак — объясни его в скобках.

Главные правила:
- Ничего не создавай и не ставь без согласия. Спросил → получил «да» → сделал → проверил → сказал, что сделал.
- Существующие файлы не перезаписывай. Если папка или файл уже есть — оставь как есть, создай только недостающее и скажи, что пропустил.
- Пароли, ключи и коды не проси и не записывай.

## Шаг 1. Где создать Второй мозг

Поздоровайся и коротко объясни, что это:
> «Второй мозг — это папка, где я храню всё о тебе и твоих проектах: кто ты, чем занимаешься, что получилось, чему научились. Так я с каждым разом работаю лучше. Где её создать? Могу в Документах: `<путь>`»

Путь по умолчанию — папка «Документы» человека + `/Второй мозг`:
- Windows: `%USERPROFILE%\Documents\Второй мозг` (если Documents перенесена в OneDrive — `%USERPROFILE%\OneDrive\Documents\Второй мозг`; проверь, какая существует).
- macOS/Linux: `~/Documents/Второй мозг`.
Покажи полный путь словами. Человек может назвать другое место.

## Шаг 2. Создать каркас

Шаблоны лежат в папке плагина: `${CLAUDE_PLUGIN_ROOT}/templates/` (если переменной нет — папка `templates` рядом с папкой `skills` этого плагина).

Создай (только то, чего нет):
```
Второй мозг/
├── CLAUDE.md      ← из templates/CLAUDE.md
├── index.md       ← из templates/index.md
├── ссылки.md      ← из templates/ссылки.md
├── feedback.md    ← из templates/feedback.md
├── Документы/      ← готовые документы, тексты, таблицы
├── Входящие/
├── Навыки/
└── Проекты/
```

Запиши метку `~/.isanagge/config.json` (создай папку `~/.isanagge`, если нет):
```json
{"brain": "<полный путь к папке, с прямыми слэшами, например C:/Users/Имя/Documents/Второй мозг>", "created": "<дата ГГГГ-ММ-ДД>"}
```
По этой метке хук в следующих сессиях найдёт Второй мозг.

Проверь, что папка и файлы на месте, и скажи человеку: «Готово, папка создана: <путь>».

## Шаг 3. Знакомство

Спроси одним сообщением, без анкеты:
> «Расскажи о себе как другу: как тебя зовут, чем занимаешься, что хочешь, чтобы я помогал делать?»

Можно голосовым — тогда см. навык `isanagge:rasshifrovka`.

По ответу заполни в `Второй мозг/CLAUDE.md` разделы «Кто я» и «Чем занимаюсь» (коротко, его словами, без выдумок). Если чего-то важного не хватает — задай максимум один уточняющий вопрос.

## Шаг 3½. Старые документы и проекты (по согласию)

Спроси:
> «У тебя уже есть документы, таблицы или проекты, с которыми мы будем работать? Могу собрать их во Второй мозг, чтобы всё было в одном месте.»

Если да:
1. Пусть человек назовёт папки или файлы (или перетащит их в чат). Сам по всему диску не ищи.
2. **Копируй, а не перемещай** — оригиналы остаются на месте. Перемещать только по прямой просьбе.
3. Раскладывай: документы, тексты, таблицы → `Документы/`; программы, сайты, боты, видео-проекты → `Проекты/<Название>/` (по навыку `isanagge:novyy-proekt`); остальное → `Входящие/`.
4. Пароли, ключи, сканы паспортов и т. п. не копируй — скажи, что пропустил и почему.
5. На каждый перенесённый документ или проект — строка в `index.md`. Скажи итог: сколько чего перенёс и куда.

## Шаг 4. Правила везде (по согласию)

Спроси:
> «Хочешь, чтобы я работал по этим правилам в любой папке, а не только во Втором мозге? Я добавлю короткий блок в твой общий файл настроек Claude.»

Если «да» — в `~/.claude/CLAUDE.md` (создай, если нет) добавь в конец блок, если его там ещё нет (ищи строку `<!-- isanagge -->`):
```
<!-- isanagge -->
# Второй мозг
Мой Второй мозг: <путь>. Перед работой читай его CLAUDE.md и index.md.
Всё, что создаёшь, сохраняй только во Втором мозге: документы — Документы/, программы и проекты — Проекты/<Название>/, входящие файлы — Входящие/. Не сохраняй на Рабочий стол, в Загрузки и временные папки без прямой просьбы. После нового файла — строка в index.md.

<раздел «Как со мной работать» из Второй мозг/CLAUDE.md — дословно>
<!-- /isanagge -->
```
Остальное в этом файле не трогай.

## Шаг 5. Навыки под дело человека

Уже есть в Isana (ставить не нужно): видео (`hyperframes`, `gsap-*`, `slideshow`, `reverse-any-video`, `media-use`, `figma`, `style-sampling`), тексты (`humanizer`), анализ (`data-analysis`, `security-audit`), поиск навыков (`find-skills`), свои: `novyy-proekt`, `zapomni-priem`, `itog-nedeli`, `rasshifrovka`, `sortirovka` (навести порядок в папках), `watch` (читать ссылки и смотреть видео).

По рассказу человека назови 2–4 самых полезных именно ему, одной строкой каждый, с примером из его дела. Если нужного нет — найди через `find-skills` и предложи (ставить только с согласия).

## Шаг 6. Программы и плагины (каждое — по отдельному согласию)

Перед установкой скажи, что ставишь, откуда и зачем. Ставь только из официальных мест ниже. Если что-то не вышло — объясни простыми словами и иди дальше; провал установки не мешает остальному.

1. **graphify** (рекомендую всем) — карта знаний по папке. Нужен Python 3.10+.
   - Проверь: `python --version` (на Windows ещё `py --version`).
   - Нет Python → скажи, где взять (python.org, при установке отметить «Add to PATH»), и пропусти шаг.
   - Есть → `python -m pip install --upgrade graphifyy` (пакет называется именно `graphifyy`), затем `graphify install` (сам подключит навык к Claude Code). Проверь `graphify --help`. Навык заработает в новой сессии: `/graphify .` в любой папке строит карту знаний.
2. **yt-dlp и ffmpeg для видео по ссылкам** — см. навык `isanagge:watch`, раздел «Установка». Предложи, если человек будет присылать ссылки на видео.
3. **Whisper для голосовых** — см. навык `isanagge:rasshifrovka`, раздел «Установка». Предложи, если человек будет присылать голосовые или работать с видео.
4. **Remotion** (если человек делает видео) — ставится только из источника и только если есть Node.js: `npx -y skills add remotion-dev/skills -g -y`. Нет Node — пропусти и скажи, что hyperframes уже умеет почти всё.
5. **Плагины** (по желанию). Если в терминале доступна команда `claude` — поставь сам; иначе дай человеку вставить строки в Claude Code:
   - superpowers (планирование и аккуратная работа): `/plugin install superpowers@claude-plugins-official`
   - frontend-design (красивые сайты): `/plugin install frontend-design@claude-plugins-official`
   - ECC (большой набор для программистов, много навыков): сначала `/plugin marketplace add affaan-m/ECC`, потом `/plugin install ecc@ecc`. Предлагай только тем, кто пишет код.
   - claude-mem (автопамять между сессиями): `/plugin marketplace add thedotmack/claude-mem`, потом `/plugin install claude-mem@thedotmack`. Предупреди: ему нужна отдельная программа в фоне, на слабом компьютере может мешать. Второй мозг и так хранит память в файлах.

## Шаг 7. Итог

Коротко:
- где лежит Второй мозг;
- что поставлено, что пропущено и почему;
- как пользоваться дальше: «Просто говори, что нужно. Новый проект — скажи "новый проект". Понравилось, как я сделал — скажи "запомни приём". Голосовые кидай в папку Входящие или прямо сюда. Ссылки и видео — просто присылай, я посмотрю. Бардак в папках — скажи "отсортируй".»

Запиши первую строку в `feedback.md`: дата, «Первый запуск Isana», что поставлено.

## Версия

На вопрос «какая версия Isana» — назови версию из подсказки хука (`[Isana X.Y.Z]`) или из `${CLAUDE_PLUGIN_ROOT}/.claude-plugin/plugin.json`. Что нового — в `CHANGELOG.md` репозитория плагина.
