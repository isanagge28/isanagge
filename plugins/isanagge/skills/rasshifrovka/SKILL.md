# Расшифровка голосовых (Whisper)

Скрипт: `${CLAUDE_PLUGIN_ROOT}/skills/rasshifrovka/rasshifrovka.py` (если переменной нет — файл `rasshifrovka.py` рядом с этим SKILL.md).

## Как работать

1. Найди файл: путь, который дал человек, или новые аудио в `Второй мозг/Входящие/`. Если человек прислал голосовое не файлом, а куда-то ещё — попроси положить его во `Входящие/`.
2. Запусти (путь всегда в кавычках):
   ```
   python "<скрипт>" "<файл>"
   ```
   (на Windows, если `python` не найден, — `py`). Модель выберется сама: есть видеокарта NVIDIA — точная `large-v3`, нет — `small` на процессоре. Видеокарта не обязательна.
3. **Не показывай расшифровку человеку.** Прочитай текст сам, как обычное сообщение от него, и сразу сделай то, что он просит (ответь, выполни задачу). Можно одной короткой фразой обозначить, что понял: «Понял — делаю пост про новую коллекцию».
4. Текст тихо сохраняется рядом с файлом (`<файл>.txt`). Покажи его, только если человек попросит «покажи расшифровку».
5. Если в тексте есть странные слова (имена, бренды) и от них зависит результат — уточни одним вопросом, а не гадай.

## Коды ответа скрипта
- `0` — готово, текст в выводе.
- `2` — файл не найден → проверь путь.
- `3` — не установлен Whisper → см. «Установка».
- `4` — не получилось (обычно нет интернета при самой первой загрузке модели) → скажи простыми словами и предложи повторить, когда будет интернет.

## Установка (один раз, только с согласия)
Скажи: «Для расшифровки поставлю Whisper — бесплатная программа распознавания речи. Нужно около 0,5 ГБ (или 3 ГБ для точной модели, если есть видеокарта). Ставлю?»
1. Проверь Python 3.9+: `python --version` (Windows: ещё `py --version`). Нет → подскажи python.org (отметить «Add to PATH») и остановись.
2. `python -m pip install --upgrade faster-whisper "av<16"` (новые версии PyAV несовместимы с faster-whisper; Python 3.9–3.12 надёжнее всего — для самых новых версий готовых пакетов может не быть, тогда способ «Без пароля» ниже)
3. Проверь на любом коротком файле. Первый запуск скачивает модель — это долго только один раз.

## Без пароля (нет Python, нет прав администратора, не получается ввести пароль)
Через **uv** — бесплатный установщик от Astral, ставится в личную папку без пароля и сам скачивает Python.
1. Есть ли uv: `uv --version` (или `~/.local/bin/uv --version`). Нет → поставь по навыку `isanagge:watch`, раздел «5Б», шаг 1.
2. Запускай скрипт так — uv сам подтянет Python и faster-whisper (первый раз — несколько минут):
   ```
   uv run --python 3.12 --with faster-whisper --with "av<16" python "<скрипт>" "<файл>"
   ```
   `--python 3.12` — для самых новых версий Python у Whisper ещё нет готовых пакетов. `av<16` — новые версии библиотеки PyAV несовместимы с faster-whisper (ошибка `unexpected keyword argument 'metadata_errors'`).
   Параметры `--model`, `--language` — так же, в конце команды. Коды ответа — те же.

## Точнее или быстрее
- Точнее (имена, бренды, смесь языков): `--model medium` или `--model large-v3` (без видеокарты — медленно, минута записи ≈ несколько минут).
- Быстрее на слабом компьютере: `--model base`.
- Язык известен заранее: `--language ru` — чуть точнее и быстрее.
