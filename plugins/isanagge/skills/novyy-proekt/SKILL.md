# Новый проект во Втором мозге

Путь ко Второму мозгу — в подсказке хука или в `~/.isanagge/config.json` (поле `brain`). Нет Второго мозга → сначала навык `isanagge:start`.

1. Если из разговора неясно — одним вопросом узнай: как назвать проект и в чём его цель (что будет «готово»).
1½. Реши, какой проект (спроси, если неочевидно):
   - **Лёгкий** — тексты, документы, таблицы, планы, сценарии → весь проект во Втором мозге (шаги ниже как есть).
   - **Большой** — программа/сайт/бот с кодом или тяжёлые медиа (видеоисходники, сотни МБ) → во Втором мозге только **карточка**, сам проект — отдельно:
     - код → папка на диске вне Второго мозга (например `~/Projects/<Имя>`); в GitHub — только по правилу «GitHub» ниже;
     - тяжёлые медиа → отдельная папка в облаке вне Второго мозга или внешний диск.
     Зачем так: Второй мозг остаётся лёгким и быстро синхронизируется между компьютерами, а Claude читает карточку, не тратя силы на весь проект. В карточке храни **ссылку** (GitHub, папка Google Диска), а не путь вида `/Users/...` или `C:\...` — путь на другом компьютере другой. Если ссылки нет — запиши путь и пометь, на каком компьютере он верен.
2. Имя папки: коротко, по-русски или латиницей, без `/ \ : * ? " < > |`. Если такая папка уже есть — не трогай её, спроси, продолжить там или назвать иначе.
3. Создай `Проекты/<Имя>/`:
   - `CLAUDE.md`:
     ```
     # <Имя>
     Цель: <одной фразой>
     Для кого: <если сказано>
     Где лежит сам проект: <для большого — ссылка на GitHub / папку облака; для лёгкого — «здесь»>
     ## Решения
     <!-- важные решения с датой: что решили и почему -->
     ## Правила проекта
     <!-- особые правила для этого проекта -->
     ```
   - `index.md`: `# <Имя> — оглавление` + список файлов/разделов (пока пусто).
4. Добавь строку в раздел «Проекты» общего `index.md`: `- [<Имя>](Проекты/<Имя>/index.md) — <цель>`.
5. Дальше все файлы лёгкого проекта клади в его папку; у большого — работай в месте, указанном в карточке, а в карточку (`CLAUDE.md` проекта) записывай решения и ссылки. Важные решения записывай в его `CLAUDE.md`, уроки — в общий `feedback.md`.
6. Скажи человеку: «Проект создан: <путь>». Если работа будет в отдельной программе (сайт, бот) — предложи открыть в Claude Code как рабочую папку место, где лежит сам проект (для большого — его папку или скачанный из GitHub репозиторий).

## GitHub — только с согласия и каждый раз с вопросом

- **Сам ничего не загружай в GitHub.** Ни проект, ни файлы Второго мозга (CLAUDE.md, журнал, уроки, приёмы, документы). Только когда человек сам попросил загрузить конкретный проект.
- **Каждый проект — в своём отдельном репозитории** (своя ссылка). Никогда не клади личные проекты в репозиторий плагина или в чужой проект.
- **Перед созданием репозитория всегда спроси:**
  > «Как загрузить <проект>?
  > 1. **Закрытый — для себя** (видишь только ты; советую для личных проектов и всего, что в работе).
  > 2. **Открытый — для всех** (любой может найти и скачать; для готовых плагинов и того, чем хочешь делиться).»
  Без ответа не создавай. Не знаешь — предлагай закрытый.
- **Перед открытым** проверь, что в загружаемом нет личного: имён и телефонов, почты, адресов, паролей, ключей и токенов, путей вида `/Users/<имя>` или `C:\Users\<имя>`, имени компьютера, файлов из Второго мозга. Нашёл — покажи и убери до загрузки.
- Запиши ссылку и выбор (закрытый/открытый) в карточку проекта (`Где лежит сам проект`) и строку в `ссылки.md`.
