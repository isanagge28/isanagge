# Чужие навыки внутри Isana

Эти навыки скопированы без изменений из официальных открытых репозиториев. Их лицензии разрешают распространение; тексты лицензий — в папке `third_party_licenses/`.

| Навыки | Источник | Коммит | Лицензия |
|---|---|---|---|
| hyperframes, hyperframes-cli, hyperframes-registry, figma, media-use, remotion-to-hyperframes, reverse-any-video, slideshow, style-sampling | https://github.com/heygen-com/hyperframes | 196eff3 | Apache-2.0 |
| gsap-core, gsap-frameworks, gsap-performance, gsap-plugins, gsap-react, gsap-scrolltrigger, gsap-timeline, gsap-utils | https://github.com/greensock/gsap-skills | aed9cfd | MIT |
| find-skills | https://github.com/vercel-labs/skills | 57217cf | MIT |
| humanizer | https://github.com/blader/humanizer | a32f244 | MIT |
| data-analysis | https://github.com/claude-office-skills/skills | 9c4c7d5 | MIT |
| security-audit | https://github.com/cloudflare/security-audit-skill | c1c8a8c | MIT |

Ставятся из источника при первом запуске (навык `start`), с согласия человека:
- graphify — `pip install graphifyy` + `graphify install` (https://github.com/Graphify-Labs/graphify, Apache-2.0)
- faster-whisper — `pip install faster-whisper` (https://github.com/SYSTRAN/faster-whisper, MIT)
- Remotion skills — `npx skills add remotion-dev/skills` (https://github.com/remotion-dev/skills)

Свои навыки Isana (start, novyy-proekt, zapomni-priem, itog-nedeli, rasshifrovka), шаблоны и хук — лицензия MIT (файл `LICENSE`).
