# Что нового в Isana

Номер версии: `БОЛЬШАЯ.СРЕДНЯЯ.МАЛАЯ`
- малая (0.1.**1**) — исправили ошибку;
- средняя (0.**2**.0) — добавили навык или возможность;
- большая (**1**.0.0) — крупные перемены, что-то работает по-новому.

Текущая версия всегда записана в `plugins/isanagge/.claude-plugin/plugin.json`.
Спроси у Claude «какая версия Isana?» — он ответит.

## 0.5.1 — 2026-11-23
- Второй мозг в облаке теперь называется «Облачный Второй мозг» — и папка, и в словах Claude. На компьютере без облака — по-прежнему «Второй мозг». Облачная папка со старым именем «Второй мозг» тоже признаётся.

## 0.5.0 — 2026-11-23
- Выбор, где держать Второй мозг: только на компьютере, на компьютере + копия в облаке (Google Диск, iCloud, Dropbox, OneDrive) или подключить уже существующий. Claude сам находит установленные облака.
- Новый навык `sinhronizaciya`: перенести Второй мозг в облако в любой момент, подключить второй компьютер, синхронизировать приёмы.
- Приёмы (`zapomni-priem`) теперь хранятся во Втором мозге (`Навыки/<имя>/SKILL.md`) и подключаются на любом компьютере: хук при старте сам замечает неподключённые.
- Журнал «где остановились» (`журнал.md`): Claude пишет его в конце работы и при старте напоминает, на чём остановились и на каком компьютере.
- Большие проекты (код, тяжёлые медиа) — в GitHub или отдельной папке, во Втором мозге только карточка со ссылкой. `sortirovka` предлагает вынести тяжёлое и находит следы конфликтов облака.
- Если облако не запущено и Второй мозг недоступен, Claude не создаёт новый, а просит запустить облако.
- Исправлено: хук не находил Второй мозг, если в метке `config.json` было несколько полей в одной строке.

## 0.4.1 — 2026-11-23
Исправления после проверки на настоящем видео (Mac на Apple Silicon, установка без пароля):
- Расшифровка: новые версии PyAV ломали faster-whisper (`metadata_errors`) — теперь ставится `av<16`; без пароля Whisper запускается на Python 3.12 (для 3.15 готовых пакетов ещё нет).
- `watch`: субтитры только оригинальные (`ru,en,ru-orig,en-orig`) — шаблон `ru.*` тянул автопереводы, и YouTube отвечал 429.
- `watch`: ставится deno — без него yt-dlp плохо работает с YouTube.
- `watch`: ffmpeg без пароля копируется, а не ярлыком — ярлык ломался после очистки кэша uv.

## 0.4.0 — 2026-11-23
- Установка без пароля: если нет Homebrew, нет прав администратора или пароль не вводится, `watch` ставит yt-dlp и ffmpeg через uv (официальный установщик от Astral) в личную папку, а `rasshifrovka` запускает Whisper через `uv run` — Python ставить не нужно.
- Подсказка новичку: при вводе пароля в терминале ничего не видно — это нормально.
- `watch`: субтитры и звук теперь скачиваются без перекодирования — для них ffmpeg больше не нужен, он нужен только для кадров.

## 0.3.0 — 2026-11-23
- Новый навык `sortirovka`: раскладывает Второй мозг по полочкам — неразобранное из Входящих и корня, документы проектов, проекты без своей папки, битые строки в оглавлении. Сначала показывает план, ничего не удаляет.
- Напоминание при каждом старте: перед созданием файла решить, в какую папку он ляжет. Хук считает неразобранные файлы во Входящих и в корне и предлагает их разложить (только считает, ничего не трогает).
- Новый навык `watch`: читает любые ссылки — статьи, сайты, PDF — и смотрит видео (YouTube, Rutube, VK, TikTok, Reels и др.): субтитры или расшифровка через Whisper плюс кадры, чтобы видеть, что на экране. yt-dlp и ffmpeg ставятся только с согласия.

## 0.2.0 — 2026-11-23
- Главное правило хранения: всё, что создаёт Claude (документы, таблицы, программы, сайты, видео, скачанное), сохраняется только во Втором мозге и записывается в `index.md`.
- Новая папка `Документы/` в каркасе и раздел «Документы» в оглавлении.
- При первом запуске Claude предлагает собрать старые документы и проекты во Второй мозг (копией, оригиналы остаются на месте).
- Правило хранения действует и вне папки (через общий файл правил — по согласию).

## 0.1.0 — 2026-11-23
Первая версия.
- Создание папки «Второй мозг» при первом запуске (спрашивает, где).
- Знакомство: человек рассказывает о себе, Claude подстраивается.
- Навыки: `start`, `novyy-proekt`, `zapomni-priem`, `itog-nedeli`, `rasshifrovka`.
- Расшифровка голосовых через Whisper — бесплатно и без интернета.
- Навыки по видео (HyperFrames, GSAP), текстам (humanizer), анализу (data-analysis, security-audit; graphify ставится при первом запуске), поиск навыков (find-skills).
